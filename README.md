# BetZone — Full Betting Platform Prototype

This is a front-end prototype for a sports betting + casino platform.

## Included
- Sports matches and demo odds
- Bet slip
- Virtual UGX wallet
- Bet history
- 20 casino/crash-style demo games
- Admin dashboard
- Responsive mobile layout

## Run
Open `index.html` in a browser.

## Important
This build uses virtual/demo money only. It is not a real-money gambling service.

Before any real-money launch, the operator would need to address applicable gambling licensing, age/KYC verification, responsible-gambling controls, AML/fraud controls, compliant payment providers, secure account handling, regulated sports-odds/data providers, game-provider licensing, and local legal requirements.
